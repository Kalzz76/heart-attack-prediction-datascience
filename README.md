# Heart Attack Risk Prediction - Data Science & Machine Learning

Proyek analisis data dan model Machine Learning untuk klasifikasi risiko serangan jantung menggunakan Orange Data Mining dan Python.

## Fitur & Konten Proyek:
- **Dataset:** Data rekam medis pasien jantung (`Heart Attack.csv` & `DATASET_BERSIH_KakaAndrea.csv`).
- **Orange Workflow (`.ows`):** Pipeline preprocessing, visualisasi korelasi fitur, dan evaluasi model klasifikasi.
- **Laporan Proyek (`.docx`):** Dokumentasi metodologi, metrik evaluasi (akurasi, presisi, recall), dan analisis temuan.
